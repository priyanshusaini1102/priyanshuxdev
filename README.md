# Priyanshu Saini

Consulting site for app and backend development, with AI as part of the work. Vite + React. `main` deploys on Vercel from `npm run build` to [priyanshuxdev.vercel.app](https://priyanshuxdev.vercel.app).

All copy is in [`src/content.js`](src/content.js). SEO tags, `robots.txt`, and `sitemap.xml` are generated from that file.

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
