# Priyanshu Saini

Personal site for a Node.js backend engineer building with AI.

Stack: Vite + React, static `dist` output. `main` deploys on Vercel at [priyanshuxdev.vercel.app](https://priyanshuxdev.vercel.app). Build command stays `npm run build`.

All copy, links, projects, and notes live in [`src/content.js`](src/content.js). SEO tags, `robots.txt`, and `sitemap.xml` are generated from that file at build time.

## Edit

- Instagram is a placeholder. Set its `href` in `socials`.
- Notes are markdown strings on `writing.posts`.
- Layout and theme live in `src/index.css`.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
